# Documentation for LazyPurple's MvM Server

This page is for the more technical side, storing some of the popfiles that are otherwise contained within the server.

The *Missions* folder contains all missions currently available on Servers #1, #2, and #3.

The *Archived Missions* folder contains all missions exclusive to the experimental 30-player server, as well as missions that are no longer available.

The *Script Files* folder contains all scripts on the active rotation of the server.

The *Archived Script Files* folder contains all scripts used for missions in the *Archived Missions* folder.

The *Templates* folder contains all files that define the robots.

To get the icons to load in-game, download the .vtf and .vmt for that icon and place them in tf/materials/hud.
Then type hud_reloadscheme in console.
You can access these icons here: https://bit.ly/lazyasset
